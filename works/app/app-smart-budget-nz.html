SmartBudget NZ

A minimalist expense tracker designed for everyday life in New Zealand. Record purchases, organise household spending, compare supermarket prices, and keep an NZD-to-JPY reference in one place.

View Source on GitHub

Source code and project details; no public demo is currently available.

01

Project Overview

SmartBudget NZ is a minimalist expense-tracking app built to make everyday living costs in New Zealand easier to understand. It brings expense entry, receipt capture, household spending, and supermarket price comparisons together in a mobile-first experience.

02

Key Features

  • Flexible expense entry: Add purchases manually or capture receipt details, including from iPhone HEIC images.
  • Quick store selection: Choose common New Zealand retailers such as PAK'nSAVE, New World, Woolworths, Kmart, and The Warehouse.
  • Detailed categories: Organise spending into main categories and subcategories for a clearer household budget.
  • Shared household tracking: Distinguish expenses by household member with customisable visual identifiers.
  • Supermarket price checks: Compare product prices across stores and keep track of standard and sale prices.
  • Currency reference: Check NZD against JPY using real-time or manually set exchange rates.
03

Design Approach

Clarity through a monochrome interface

A restrained black-and-white visual foundation keeps the interface calm and focused on spending information, while subtle user-specific accents help distinguish shared expenses.

Practical, local-first workflows

Store shortcuts, receipt capture, and currency references are tailored to the day-to-day needs of people managing expenses in New Zealand.
